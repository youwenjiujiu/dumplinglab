# Your Choice: filling-specific cutaway images

Built-in imagegen skill/tool used, one fresh generated asset per filling/preparation. No API/CLI fallback. These are generated food visuals, not actual restaurant photographs. Existing two recommended pan-fried cutaways are retained. Thirteen additional cutaways complete five dumpling fillings across tossed, boiled and fried preparation, for 15 distinct images total. Wonton imagery and catalogue/checkout rules are unchanged. Photos show the filling, not an exact promise of the selected serving count; five/nine portions remain explicit text controls.

## Assets and final prompts

All source PNGs live in web/img. Matching WebPs live in web/img/s and web/img/l, generated using the existing optimise-images.mjs script with alpha preserved. This release does not delete the old generic images.
