# Dumpling Lab · 设计与动效准则（蒸馏版）

来源：emilkowalski/skills（design-eng / animate / review-animations / apple-design）与 yanliudesign/mono-color-skill。
只保留能直接落到这个点餐站上的规则。每条都是"必须"，不是建议。

## 一、动效：先问要不要动

| 频率 | 决定 |
|---|---|
| 每天上百次（键盘、切分类、滚动） | **不动** |
| 每天几十次（点 + 加菜、hover） | 只允许几乎察觉不到的反馈：`scale(.97)` 100–160ms |
| 偶尔（票据抽屉、菜品页、弹层） | 标准动效，**≤300ms** |
| 稀有 / 第一次（下单成功） | 这里才允许"惊喜"：落章、轻微弹跳 |

动的理由只能是五个词之一：**反馈 / 空间连贯 / 状态变化 / 避免跳变 / 说明**。"好看"不算。

## 二、动效的配料（不许自创）

```css
--ease-out:    cubic-bezier(0.23, 1, 0.32, 1);   /* 进场、出场、默认 */
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);  /* 在屏幕上移动/变形 */
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);   /* 抽屉、底部弹层（iOS 曲线） */
```

- 进出场 `ease-out`；屏幕上移动 `ease-in-out`；hover/颜色 `ease`；匀速 `linear`。**永远不用 `ease-in`。**
- 时长：按压 100–160ms；小弹层 125–200ms；下拉 150–250ms；弹层/抽屉 200–500ms。出场比进场快。
- 只动 `transform` 和 `opacity`（`clip-path` 例外）。不动 width/height/margin/top。
- **不从 `scale(0)` 出现**：从 `scale(.95–.97) + opacity 0`。
- 会被连续触发的东西（toast、加号、切换）用 **transition** 不用 keyframes——transition 可被打断重定向，keyframes 从零重来。
- `transition: all` 禁止；写明属性。
- 弹跳（bounce）只给"带动量的手势"（甩、拖放）和稀有时刻；菜单、抽屉、按钮不弹。
- 用手势的东西用弹簧（可打断、继承速度）；`prefers-reduced-motion` 下保留透明度过渡、去掉位移；hover 动效必须包在 `@media (hover:hover) and (pointer:fine)` 里。
- 进场用 `@starting-style`，不用 JS 定时器。

## 三、触感（Apple）

- **按下即反馈**（pointerdown），不是松手才反馈。任何可按的东西都有 `:active { transform: scale(.97) }`。
- 拖动 1:1 跟手、尊重抓取偏移、`setPointerCapture`；松手把速度交给动画（velocity handoff）；边界用橡皮筋不用硬墙。
- 进场和出场走同一条路（底部弹层从底部来、回底部去）。
- 顶栏/工具栏是**半透明材质**（`backdrop-filter`），内容从下面滑过；用"滚动边缘渐隐"代替 1px 分割线。
- 字号越大字距越负（大标题 `-0.02em`），越小字距越正（小号大写 `+0.12em`）；大标题行高 1.05–1.15。层级靠 字重+字号+行高 一起，不只靠字号。

## 四、版式（mono-color）

- 一页只有**一个焦点事件**（一张大图、一个大字），其余全部退让；留一块**明显更安静的释放区**。
- 纸面外露 **25–55%**。
- 字体 **≤3 种声音**，标题与标签之间要有明显的尺度跳跃（海报 5×以上；界面至少 2.5×）。
- 颜色有"角色"：主色承载图像与大字，副色只做标签与数字，不做装饰。
- 硬性回避：卡片网格式的模板对称、贴纸感、装饰性色块、无意义渐变、长段文案、营销口号。
- 参考只借语法不借版面：换掉至少四个结构变量。

## 五、落到 Dumpling Lab

- **每页一个焦点**：封面 = 一道菜；菜单页 = 格子里的菜；菜品页 = 大图。logo 是签名不是焦点，除封面外保持小。
- **红有角色**：logo、加号/数量、价格、下单轨、主按钮、票据抬头、成功页。文字、分割线、底色不碰红。
- **三种字**：思源宋体（中文标题与菜名）、Josefin Slab（英文、价格、标签——与 wordmark 同一支笔）、系统黑体（正文、按钮）。
- **动效预算**：加号按下 `scale(.94)` 120ms；票据抽屉 380ms `--ease-drawer`，关闭 260ms；视图切换（封面→菜单→菜品）200ms 淡入 + `scale(.985)`；toast 从底部来回底部去；成功页允许落章（唯一的弹跳）。
- **不动的**：切分类、滚动、搜索、语言切换、任何键盘触发。
