# 3D 菜品管线（就绪，待新图）

**状态（2026-08）**：技术全部打通并验证。决定 **B** —— 暂不批量生成，
等摄影师的斜角新图再转。现有管线一行命令即可全量生成。

## 为什么等新图

图生3D 只能重建照片里"看得见"的深度。现有菜品照是**俯拍**，模型看不到
碗壁/立体，会挤成一张浅浮雕盘。斜角照能显著改善立体感。

## 给摄影师的拍摄要求（为 3D 优化）

- **角度**：45° 斜俯拍（不要正俯拍），能看到食物的高度和容器侧壁
- **背景**：纯色/浅色、无杂物，主体与背景对比清晰（便于抠图 + 图生3D 分割）
- **单主体**：一次一道菜居中，避免多盘穿插
- **打光**：柔和均匀，避免硬阴影和高光过曝
- 常规平面菜单仍可用同一批图（照片本身照常用）

## 新图到位后怎么做（全自动）

    # 1) 新照片抠底放进 web/img/<dish-id>.png（沿用现有命名）
    # 2) 生成 3D（一次性，静态文件，之后零运行时成本）
    export FAL_KEY="<你的 fal.ai key>"
    node scripts/gen-3d.mjs                 # 全部缺模型的菜
    node scripts/gen-3d.mjs beef-yolk-bowl  # 单道测试
    MODEL=hunyuan node scripts/gen-3d.mjs   # 换更强的模型（更贵）
    # 3) 生成物落在 web/models/<id>.glb，菜单自动加载，无则回退照片/插画

## 组成

- 生成：scripts/gen-3d.mjs（fal.ai，默认 TRELLIS，可切 hunyuan3d）
- 渲染：web/dish3d.js（Three.js 影棚查看器 — 拖动旋转/惯性/自转/陀螺仪/接触阴影）
- 试验台：web/3d.html?dish=<id>
- 依赖：web/vendor/（three@0.160 + GLTFLoader，无构建步骤）

## 成本

fal TRELLIS 约 $0.05/道；全菜单一次几毛钱。生成后是静态 GLB，扫码零 API 费用。
