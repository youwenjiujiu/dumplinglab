# 菜品空间预览：摄影要求

当前正式体验直接使用摄影师交付的透明 PNG，因此照片本身就是顾客看到的菜品，不会被 AI 重画。

## 单张主图：用于当前原图 3D

- 角度：菜品上方约 35–45°，同时看清食物顶部、容器正面和完整边缘。
- 构图：容器不能裁切，四周至少留 12–15% 空间；主体视觉中心保持居中。
- 镜头：全画幅等效 50–85 mm，避免超广角和手机人像模式的轮廓错误。
- 清晰度：整盘都清晰，推荐 f/8–f/11、低 ISO；不要只清楚一颗饺子。
- 光线：大面积柔光加弱补光，保留柔和接触阴影；避免汤面过曝和金属盘死白。
- 背景：纯色哑光暖灰或浅米白，与碗盘有清晰边界，方便制作干净透明通道。
- 文件：RAW 原片 + 修好的透明 PNG，长边至少 3000 px，固定白平衡，不要微信压缩图。
- 一致性：拍完前不要移动葱花、汤汁或摆盘；最终 PNG 要从这张 RAW 修出，不做生成式增删。

## 如果未来要做大角度真实旋转

不是再拍一张，而是拍一段连续环绕短视频或 40–80 张重叠照片：

- 菜品、桌面和灯光全程固定；相机绕菜走，不能转盘后让高光跟着盘一起转。
- 覆盖正面、左右、略高和略低视角，相邻帧至少 70% 重叠；透明汤和反光金属需要交叉偏振。
- 手动锁定曝光、焦距、白平衡和对焦；不要开防抖裁切、HDR 合成或背景虚化。
- 另拍一张灰卡 / 色卡和空背景，供颜色校正与遮罩。

多角度素材才能用摄影测量或 Gaussian Splat 保留真实侧面。只有单图时，隐藏面必然是推断，
因此正式页面只开放小角度空间视差。

## 命名

主图：`dish-id/main-45deg.png`

多角度素材：`dish-id/orbit/frame-0001.jpg` 起连续编号。

`dish-id` 必须与 `web/menu-data.js` 一致，例如 `hk-crab-roe-wonton`。
